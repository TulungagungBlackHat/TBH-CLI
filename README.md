## ✨ Features CLI
- Headers + Ports saja - cepat, tanpa file output
- Pure terminal, warna, tanpa `report.json`/`report.html`

## 📦 Install
```bash
git clone https://github.com/TulungagungBlackHat/TBH-CLI
cd TBH-CLI
python3 tbh -u https://example.com
```

## 🚀 Usage
```bash
python3 tbh -u https://example.com
# Output langsung di terminal, tanpa file
```

## vs AllScan
- **AllScan**: Lengkap 10 tools + JSON/HTML/Fix (untuk laporan)
- **CLI**: Ringan 2 tools + pure terminal (untuk cek cepat)
